# Occupancy data containing false absences

By loading simulatedifm this object is loaded.

## Format

- `z.sim.20.fa`:

  nyear x nsite occupancy data containing false absences, which can be
  used to explore the bias of ifm.missing.MCMC and ifm.naive.MCMC when
  there is imperfect detection.

## Details

This dataset was created using the code included in **Examples**, in
`simulatedifm`.
